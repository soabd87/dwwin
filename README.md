# دوون (dwwin)

---

##  وصف المشروع
مشروع مدونة خفيفة وسريعة مبنية باستخدام لغة بايثون (Python) وإطار عمل فلاسك (Flask). تتميز المدونة بتصميم "Minimalist" يعتمد بالكامل على الألوان الأحادية (الأسود، الأبيض، والرمادي) للتركيز التام على المحتوى المقروء بعيداً عن المشتتات البصرية.

---

## المميزات
* **تصميم نظيف وبسيط:** واجهة مستخدم تعتمد على الأبيض والأسود فقط لتجربة قراءة مريحة.
* **لوحة تحكم للمدير:** واجهة خاصة لإضافة، تعديل، وحذف المقالات بكل سهولة.
* **نظام التصنيفات:** إمكانية ترتيب وتصنيف المقالات في أقسام مخصصة.
* **حماية وأمان:** نظام تسجيل دخول وتسجيل خروج خاص بمدير المدونة فقط.
* **إعدادات مرنة:** إمكانية تغيير اسم الموقع وتحديث بيانات الدخول من لوحة التحكم مباشرة.
* **قاعدة بيانات خفيفة:** يعتمد على SQLite لسهولة الإدارة والنقل بدون تعقيدات.

---

## متطلبات التشغيل

* نظام تشغيل Linux (التعليمات أدناه مخصصة لتوزيعة Debian)
* Python 3
* بيئة بايثون الوهمية (venv)

## طريقة التشغيل على لينكس ديبيان (Debian Linux)

لتشغيل المشروع على جهازك الشخصي، اتبع الخطوات التالية:
